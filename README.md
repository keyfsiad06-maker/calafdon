# Calaf

A responsive Calaf concept for a Somali matchmaking platform, built with plain HTML, CSS, and JavaScript.

## Run locally

Double-click `Start-Calaf.bat` to open the interactive platform demo in your default browser. Open `index.html` for the marketing landing page or `app.html` for the platform experience. No installation or file copying is required. The people are original illustrations rather than real profile photos. Google Fonts need an internet connection; the layout still works without them.

## Included screens

- Landing page
- Discover and thoughtful introductions
- Connections
- Messages (demo conversation)
- Profile
- Membership
- Settings and safety

## Before launch

This is a front-end prototype with sample profiles and demo interactions. It does not have real accounts, a database, messaging delivery, payments, or a working waitlist. Connect secure services and add production privacy, consent, moderation, and safety systems before collecting personal information or launching it as a live matchmaking service. Replace sample profile details and testimonial content before launch.
